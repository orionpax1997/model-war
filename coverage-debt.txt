# 未覆盖改动登记(ADR-0038 §六)。格式:  <相对仓库根的路径>  # <为什么现在不测>
#
# 指向这张表的是四类红(判据在 packages/tools/src/scope/check.ts):
#   1. 行为输入没有任何测试观测到它(map 里一条都没有);
#   2. 逐文件探针:确知为零(0 条用例);
#   3. 逐文件探针:选中的全部 skip;
#   4. 逐文件探针:只选中结构测试(它证的是别的文件的形状)。
# 其余的红不在本表里找出口:测试候选红了 → 先修测试;读不到探针报告 → 先修探针;
# 观测快照过期 → 重录;路径说不清 → 给 RADIUS 加一条规则。
#
# 登记一行就放行,所以这张表的用途不是清零,而是让债务可见:每一行都是一个已知的判据缺口,
# 而不是一个谁都没注意到的缺口。
#
# 什么时候该登记:改了行为、确实没有便宜的办法测,而且你有意不做。
# 什么时候不该登记:只是还没写用例——那就去写,这张表不是它的替代品。
