# 14: 契约自证与等效命题 ② 的复验

**What to build:** 一条命令回答四个外部可问的问题：

1. 三份基准脚本**零静态违规**（契约没有把合规脚本判死）；
2. 三份都**打出正常终局**，不被判负出局；
3. 三份的**消耗中位数都落在总储量的四分之一以内**——这一条就是规则侧挂账的那笔账，等效命题 ② 的复验；
4. 三份的**取策略互不相同**（区分度的可观测代理：若三份脚本的行为指标收敛到同一形态，规则集就还没被证明有区分度）。

复验跑在**标定环那个已经跑过 1336 场的桩**上，桩**不搬不修**——搬桩等于改一个已经产出记录的证据源，动了那些记录就不可复现。本票的产品写在自己的工作目录里，只引用桩的代码。

**Blocked by:** 13（基准脚本落库）

**Status:** ready-for-agent

- [ ] 一条命令跑完上面四问；断言对象是**外部可观察行为**，不是生成器排版、不是区块抽取实现、不是规则表每一行
- [ ] 复验结论**引用两条口径**：(一)「整局约四百四十」那个数是单矿储量 125 时代、全矩阵平均，**不是「四份基准脚本」的数**（基准脚本口径实测三百五十一）——这条命题的松紧度是被储量那一刀改掉的，不是被地图改掉的；(二) 种子维度对消耗指标**零方差**，每臂的有效独立样本只有 4 个座位轮转，**不得写成「128 场独立样本」**
- [ ] 复验的矩阵与标定环那一轮**同夹具、同臂数**，否则数字不可比；跑正表前先过夹具闸门
- [ ] 每问**各有一个能被弄红的反例**：把配额改小 → ③ 变红；把一份脚本换成违规脚本 → ① 变红；三份换成同一份 → ④ 变红
- [ ] 换一份契约版本 → 这条缝仍绿，但**四问的取值会变**；这一点在说明里写清，避免后来者把取值当回归基线
- [ ] 复验结论**不覆盖 ① 号命题**（枯竭窗口落在 400–600）：它的返工方向是重推窗口、触发条件是「出现一个移动层不同的探针」，属规则侧后续工作。本票在文档里**只留指针**
- [ ] 结论落成规则侧记录的更新：**只更新已过的那一条**，另一条的状态与触发条件一字不改
- [ ] 桩的取数口径若与三份脚本的实际情况不符（口径是旧四舱的），**记下来而不是悄悄换口径**——换口径的代价是新旧结论不可比
