# 09: 机制契约——经济、采集、生产与战斗轮转

**What to build:** 机制文档的散文改写：经济节、采集节、生产节、战斗结算节。

这一批裁掉的是**事实性错误**而不是措辞偏好：草案写「先占矿才能采」，而终稿规则是开局就拥有家附近一圈资源点、其余资源点须先占领才有开采权；「满载 20 个有效采集 tick」里的「有效」在草案里没定义；轮转方向在草案里还标着「方向为假设，待终稿确认」——终稿要定死，并保留「先手随 tick 轮转，不要赌先手」这句结论。

**Blocked by:** 04（数值表区块）

**Status:** resolved

- [x] 「先占矿才能采」改写成终稿口径：**开局你已拥有家附近一圈资源点；其它资源点须先占领才有开采权**，两个数（占领耗时、初始资源）引数值表不重抄
- [x] 「满载 N 个有效采集 tick」的**有效**被定义出来（站在己方资源点相邻格且携带未满），展开句写进文档
- [x] 轮转方向**定死「值大者胜」**，草案的「方向为假设 / 待终稿确认」标注删干净；结论句「先手随 tick 轮转，不要赌先手」保留
- [x] 「轮转 ≠ 永远后手」那句结论保留，且与轮转方向的定案不矛盾（自证一遍：定死方向之后，这句话还成立吗）
- [x] 补上单农收入与单基地满产资金消耗的对比（单基地满产 2/tick vs 单农收入 0.8/tick），理由是该对比决定了这两个数为什么定在这里；结论句已清零，文档只留结论与指针
- [x] 兵种定位与设计约束节**不带数值**，数值一律引表——这节承载的是「为什么这个兵种长这样」，不是「这个兵种是几」
- [x] 「存活单位总造价分」的称谓全篇统一，**军事单位那种窄称零残留**（逐字搜一遍，不是抽查）
- [x] 文中每个资源类参数都引数值表，**手抄的第二份一处不留**

## Answer

**散文落在 §3 / §4 / §6 三节**，`§10` 一个字没动（它是生成区块，手改即红）。四节的编号与草案一致，
新增的两个小节是 `§3.1 先后手` 与 `§6.1 兵种定位`（兵种定位在草案里只在 gdd 有、契约里没有，
而票面点名要它不带数值，所以新立一节并把战斗结算顺移到 `§6.2`，与 gdd 的编号对齐）。

**唯一的机器缝是一条收窄断言，不是「正文里不许出现数字」**：新模块
`packages/tools/src/rules-doc-prose.ts` + `rules-doc-prose.test.ts`，判据是
**生成区块之外，参数键名不得与一个数字直接绑定**（中间只许空白与 `=` `:` `为` `是` `(`，
或反向的 `20 = carryLimit`），键名从 `RULESET_KEY_CATALOG` 推（含兵种键的六个子字段限定名）。
理由在模块头注里写全了：`§1` 的时间轴分段、`§3` 的示例坐标、约束里的倍数与 tick 跨度都是**规则本身**，
判据一旦宽到「正文不许有数字」，下一张票正常改写散文就会红，而红一次的代价是有人去关掉它。
判据收在赋值形态上，抓的恰好是抄取值那一种写法（草案自己的 `carryLimit(=20)`、
`resourcePerSite=125`、`captureTicks=10` 三种写法全部现做现验判红），放得过正文的正常改写。
放行一侧同样有用例：时间轴分段、示例坐标、「两倍」「相邻一格」这类表述都在放行清单里。
它放在 `unit` project 而不是 `gates` project，因为 `pnpm run check` 只跑 unit 与 property——
放进 gates 就等于没人每次都跑。

**「轮转 ≠ 永远后手」自证（定死方向之后仍然成立）**：优先值 `(tick + playerIndex) mod 4`、值大者胜。
取座位号相差 d 的两方、低位方优先值 `u = (tick + 低位号) mod 4 ∈ {0,1,2,3}`，高位方的优先值是
`(u+d) mod 4`，它大于 `u` 当且仅当 `u+d < 4`，即 `u < 4−d`，恰好 `4−d` 个取值——高位方在
`(4−d)/4` 的 tick 里先动，低位方在 `d/4` 的 tick 里先动。两个数都大于零（d=1 是三比一、d=2 是一比一），
所以**没有一方是永远后手**，那句话成立，而且现在有了可复核的推导而不只是一句结论。

**顺带发现并改掉一处上游矛盾**：gdd `§3.3` 原写「下标差 d 的两人，**低下标**在 `(4-d)/4` 的 tick 中先手」，
那是方向未定时按「值小者胜」写的。方向一旦定死为「值大者胜」，这句话与契约推导出的方向相反。
按「发现冲突就修矛盾的一方」，那一行改成高位方 `(4−d)/4`、低位方 `d/4`，并在同一句里注明
「原文写的是低下标，那是方向未定时按值小者胜写的，定死后即失效」。**若票 15 的 gdd 对账另有口径，
以那一票为准**，本票只保证契约与 gdd 现在不打架。

**「单农收入 vs 单基地满产」按硬约束写成关系、不写成两个数**：票面给了 2/tick 与 0.8/tick 两个数，
但硬约束是「手抄的第二份一处不留」「一律按键名引」，而 `2/tick` 就是 `§10` 派生量表里的
`FULL_PRODUCTION_COST_RATE`、`0.8/tick` 是 `harvestRate ÷ carryLimit`。文档里写的是
**两者之间的倍数关系**（满产消耗要显著高于单农收入，比值太小则两条路都能赢、太大则产能压过采集），
两个操作数各自按键名引 `§10`，指针指向 gdd `§5` 与 gdd `§8` 开放项 #5。这是本票刻意做的取舍：
要那两个数就得在散文里留第二份，而第二份迟早与真源分叉。

**票 10 的第三条（「自家单位堵自家产线」）在本票就写掉了**：它写的是 `§4.4` 生产节的出兵格规则，
而生产节是本票的范围；留着不写会让 `§4` 自相矛盾（队列规则缺一半）。写法和票 10 期望的一致
（格空自动续出 + 显式说明自家单位也阻塞自家产线），票 10 不必重做，只需核一遍。

**占位改写成写清去处**：不属于本票的六节全部留着，正文里写明归哪一批、以及为什么还没写。
`§7`/`§8` 指到「异常披露与终局措辞」那张票；`§1`/`§2`/`§5`/`§9` 四节**没有任何一张票认领**，
占位里写「本节未排期」并写清它该写什么——不编一个去处，编出来的指针下一张票就得替它圆。

### 票面之外的几条判断

1. **改了 gdd 一行**（理由与改法见上）。若本票被判为越界，那一行回滚即可，代价是契约与 gdd
   留着方向相反的两句话直到票 15。
2. **`§4.1` 的采集/交付/归属仍是一个代码块**，块内也不许有取值——草案那个块里就有
   `carryLimit(=20)` 与 `resourcePerSite=125`。代码块是模型最容易整段照抄的形状，所以门禁
   不豁免它。
3. **草案 `§4` 里那段「全图储量参考剖面（N=16 / W=8 / η=0.5 / 总量 2000 / tick 500 耗尽）」没有搬**：
   它是 125 时代的数，且 gdd 记录 #8/#13 已把它证伪。那段的重写归「终局形态与资源枯竭压力」
   那一批（票 10 的后两条），本票只留机制事实（单点有限储量、采空后点位仍在、占多少矿是经济上限）。
4. **草案的附录（C1~C7 操作化定义 + 标定假设）在十节骨架里没有家**，本票没建节也没搬内容：
   票 10 拥有其中两条警告句的加强，但整节该放在哪、该不该进面向模型的契约，是一个结构决定，
   不该由本票顺手塞进 `§10` 后面。
5. **`§3` 的示例保留**（3×3 坐标系三条）。它们是规则的可执行示范，不是取值；删了会让
   「交换穿行 / 链式移动」这两条只能靠读文字理解。
