# 07: API 契约（一）——脚本形态、座位自认与跨 tick 记忆

**What to build:** API 文档的散文部分改写第一批。看完这一票，模型能写出一份**在形态上完全合规**的脚本：单一入口函数、一种写法、一个正式的座位自认入口、以及关于「什么能跨 tick 记」的明确禁令。

这一批裁掉的是那轮措辞裁决里**最会让模型卡住的几条**：座位自认从「在快照里二选一猜」改成单一正式入口（实测四方跑同款位置法脚本会互相误判）、源码形态与交付名的记法自洽（只留一种写法并写明返回类型可省略，不留候选）、对象身份不跨 tick、同一单位一 tick 只留最后一个意图。

**Blocked by:** 05（错误码全定与 API / 常量表区块）

**Status:** resolved

- [x] 座位自认只留**一个正式入口函数**，语义钉进错误码表（对非己方单位返回、沙箱内即时返回），但**不**把它写成「可以用它自认座位」
- [x] 附录明确写上**「不要靠单位位置反推座位」**并给出理由（位置法在四方对称局里互相误判）
- [x] **候选二选一的措辞删除干净**——不留「二选一」「任选其一」「见上文」这类指向已不存在内容的句子
- [x] 脚本形态只留**一种写法**并写明「返回类型可省略」；**不留候选形态、不留「另一种写法」**
- [x] 交付名与源码形态自洽（源码是单文件 TS，交付名与入口字面不打架）
- [x] 跨 tick 记忆的禁令写成正面可执行的说法：**只存数值 id 与自己的模块级变量，不缓存对象引用、不缓存查询结果**
- [x] 「同一单位一 tick 提交多个单位级意图 → 只留最后一个，静默丢弃，不计异常」写进形态约束
- [x] **文档里每一个可运行示例都真能编译过**（用 06 落下的那份配置）。这是本票唯一的机器缝，但它把散文从「读起来对」变成「跑起来对」
- [x] 例子里的每个 API 名字都在符号表里——沿用 05 那条断言，不在本票另立一份

## Answer

### 落点

散文只改 `docs/rules-v1/api.md` 的 §1 与 §6 两节（各一个 `TODO(→…)` 占位），§3/§4/§5 一字未动
（漂移检查逐字节比过）。新增一个测试文件 `packages/tools/src/api-example-compile.test.ts`，是本票
的机器缝。

### 机器缝的实际形态

**判据是内容判，不是受判节清单。** 「可运行示例」= 围栏块里声明了顶层入口 `function loop(`。
用受判节清单（把 §1、§6 列进去）会在票 08 新写一节示例时静默失效——新写的人不会记得登记，而登记
一旦漏掉那道缝就在那一节上没了。用内容判没有这个漏法：入口声明是契约里唯一一句「这是一份完整脚本」
的话，块里没有它就只是片段（§3 生成区块里那个两行判别片段正是这种，不该被拉进编译）。

**类型面未回填，于是判的不是「退出码 0」而是「只差类型面这一件」。** 真编译是真的在跑（派生一份只覆盖
`files`/`outDir` 的运行配置，`extends` 票 06 那份 `tsconfig.scripts.json`，临时目录在仓库外，
`types` 为空），三条断言：

1. 退出码**非零**——类型面没来，示例用到 API 就必然编不过。零退出在这里是坏消息：它意味着有人偷偷
   替 API 填了声明，而那是回填那一格的活（spec 明确 Out of Scope）。
2. **全部**诊断都是「找不到名字」这一类（TS2304/TS2552），没有别的。
3. 那些名字逐个都在 `SANDBOX_INJECTED_API_SYMBOLS` 里——即「示例里用到的每个 API 名字都在符号表里」，
   而它复用同一张表，**没有另立一份名单**（票 05 那条双向断言的同一份数据）。

第 2、3 条合起来是真能抓东西的：多一句 `document`、多一个 `import`、多一处 `noUncheckedIndexedAccess`
下的 `foes[i].x`（**本票第一版骨架就是这么写错的，被这道缝当场抓出来改成了 `for…of`**）、多一个拼错的
API 名，落到的都是「找不到名字」而名字不在表里，于是红。

**没有替类型面填任何东西**：没有 shim、没有 `.d.ts`、没有临时目录以外的落盘文件。签名对不对不是这一格
的事——签名在回填前由符号表投影给出（票 05 那张 API 表就是它的投影），这一格只保证「除了缺声明，
示例没有别的毛病」。

**回填那天的动作**：把测试里那个 `TYPE_SURFACE_BACKFILLED` 翻成 `true`，断言自动改成「退出码 0、零诊断」。
触发条件写在那个常量的注释上：真源包里那些函数声明存在的那天。

**红 → 绿闭环实测过**：往示例里插一句 `document`、把 `getObjectsByType` 拼错，两次都红（分别是第 2 条
与第 3 条命中），还原后都绿。

### 每条验收条款怎么落的

- **座位自认单一入口**：§1.2 立 `getMyIndex()` 为「唯一」来源，同时明写反向的一条——「某个 id 是不是
  我的」由动作函数回答，拿到 `ERR_NOT_OWNER`（沙箱内即时返回，那一行已在 §3 错误码表里），并点明那个码
  「答的是这个 id 归不归我，不是我是谁」。没有出现「可以用来自认座位」的写法。
- **不要靠单位位置反推座位 + 理由**：§1.2 独立成段加粗，给出的理由是四方对称开局下四家跑同一份脚本时
  反推出的座位号恰好相同、四方混战实测互相误判，并补一句快照里没有 `you`/`isSelf`、那个字段不存在。
  §6 骨架里座位只从 `getMyIndex()` 来，形态上没有第二条路可走。
- **二选一措辞删除干净**：§1 与 §6 全节 grep 过「二选一 / 任选其一 / 见上文 / 另一种写法 / 候选 A|B」
  零命中；草案那段「TODO(→终稿确认)」连同占位常量一起没了。
- **形态只留一种写法**：§1.1 写「入口是顶层声明的 `function loop()`，返回类型可省略」，并说明引擎不读
  返回值；没有第二种写法、没有「另一种写法」。§1 与 §6 两份示例本身都是这一种写法。
- **交付名与源码形态自洽**：交付名 `script.ts`、源码单文件 TS、顶层声明 `loop`，三者在一句话里对齐，
  示例第一行注释也复述了一遍。没有出现「产物是 `script.js`」这类与源码形态打架的记法。
- **跨 tick 记忆写成正面说法**：§1.4 三条——只存数值与自己算出来的东西；不缓存对象引用（查询返回的只是
  本 tick 快照副本，留着读就是过期状态，且它不会跟着单位死、不会跟着点位换主）；不缓存查询结果
  （归属会变、单位会死、资源会采空，下一 tick 要用就再查一次）。
- **同单位一 tick 只留最后一个**：§1.3 独立成节，正面写成形态约束「每个 tick 对每个单位最多调一次
  单位级意图」，并点名 `spawnUnit` 是玩家级不受此约束，再给一条可执行建议（拿不准就只提交移动）。
  后果只指向 §4 那张对照表，不复述它的取值。
- **示例真能编译过**：见上。红→绿闭环实测过。
- **示例里的名字都在符号表里**：由编译诊断投影 + 同一张符号表兜住，没有另立名单。

### 票面之外的判断

- **禁非确定源按真源的四个名字写**（`Date`/`Math.random`/`performance`/`queueMicrotask`，逐字取自
  `FORBIDDEN_GLOBAL_NAMES`），定时器写成能力陈述（「沙箱里没有定时器、没有 I/O」）而不是禁令清单的第五项
  ——真源那张表只有四条，散文往里加一项就多一处会漂的抄本。`eval` 归到「禁模块语法」那条，它的理由是
  不从任何地方取代码，与非确定源不是同一条。
- **`isError`/`errCode` 只用一行带过**（§6 末「返回值走 `isError`/`errCode` 两步判别，不猜形状」），
  两个 helper 的散文示例与「禁止用类型判断或真值猜错误返回」归票 08，没有抢。
- **§3 生成区块里那两个 `ts` 块没有纳进编译**：错误码类型别名不是完整脚本（不声明 `loop`），判别片段
  里 `unitId` 未声明（它是个片段），拉到编译里会被第 3 条判红。票 08 写 §2 的完整示例时，那份示例声明了
  入口，会被自动纳进来，不需要登记。
