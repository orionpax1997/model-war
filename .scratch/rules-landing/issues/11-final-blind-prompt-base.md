# 11: 终稿盲写 prompt 基座

**What to build:** 盲写用的 prompt 基座按终稿契约重写。基座是模型看到的**唯一**任务说明（隔离舱里它读不到别的东西），所以基座里每一句过时的话都会直接变成一份不合规的脚本。

旧基座里有两处与终稿直接冲突的句子：「从快照认出自己（二选一：候选 A 容器顺序 / 候选 B 自标记）」——终稿只有一个正式入口；「轮转方向为假设（待终稿确认）」——终稿已定死。这两处不改，重跑出来的脚本必然踩已清零的坑。

**Blocked by:** 07、08、09、10（两份契约文档的散文定稿）

**Status:** resolved

- [x] 「二选一自认候选」整段删除，换成**单一入口的调用方式**；基座**不留「记下你选了哪种候选」这类回答要求**
- [x] 「轮转方向为假设」的措辞删除，改成终稿结论；**回答要求里那条「记下你对轮转方向的假设」一并删掉**（不改会让模型把一个已定的事当悬案写进注释）
- [x] 硬约束列表与终稿逐条对齐：单文件自包含 + 入口签名 + 返回类型可省略、无模块语法、禁确定性污染源与宿主桥前缀、全整数运算、只调文档里的 API、跨 tick 只存数值 id 与模块级变量
- [x] 错误判别 helper 的用法进基座硬约束（用两个 helper 显式判别，不用类型判断或真值猜）
- [x] 「每 tick 只读快照、不另行告知你的 index」改为「入口函数就是取 index 的唯一入口」
- [x] 三支策略取向**等长、同详细度**，只换一行方向性要求；沿用旧基座那条纪律：方向性要求不得违背文档硬约束、不得照抄文档里的验收口径反推编排
- [x] 基座**留在本 feature 的工作目录**，不进生成管线的提示词数据文件目录（那是后续那一格的交付物）
- [x] 基座**随附的契约正文就是落库后的那两份文档**，不是草案的副本——重跑跑的是终稿，这是这一整轮的全部意义
- [x] 基座自身零过时表述：逐句过一遍，凡指向草案内容（候选形态、假设方向、待终稿确认、待某图定值）的句子**删或改**，不留「见上文」这类悬空指针

### 1. 硬约束条目 → 终稿条款的逐条对照（自证）

| 基座里的硬约束条目 | 终稿出处 |
|---|---|
| 单文件自包含 / 禁 `import`/`export`/`require`/`eval` | api.md §1.1「禁模块语法」+ §1 抬头（交付名 `script.ts`） |
| 入口 `function loop()`，**返回类型可省略** | api.md §1.1「形态：只留一种写法」 |
| 只调 api.md 第 3 节 API 表里的名字 + 纯 ECMAScript | api.md §1.1「可见全局」+ §3 生成表 |
| 禁 `Date`/`Math.random`/`performance`/`queueMicrotask` 与 `__` 前缀全局 | api.md §1.1「禁非确定源与宿主桥」 |
| 调不存在/已删的名字 → 该 tick 全置空 + 记一次异常，累计到 `exceptionTickLimit` 判负出局 | rules.md §8.1 第 1、2 条 |
| 全整数运算，不套 `Math.floor`、不引浮点中间量 | api.md §1.1「全整数运算」 |
| 座位只从 `getMyIndex()` 读；快照无 `you`/`isSelf`；不要靠单位位置反推；`ERR_NOT_OWNER` 不是「我是谁」 | api.md §1.2 + §3 座位自认表 / 错误码表 |
| 跨 tick 只存数值；不缓存对象引用、不缓存查询结果 | api.md §1.4（三条） |
| 错误判别只有 `isError`/`errCode` 两步，不用 `typeof`、不用真值 | api.md §2.3 + §3 错误判别 helper 表 |
| 每单位每 tick 只写一条单位级意图；`spawnUnit` 不受此限 | api.md §1.3 |
| 先读基地的 `producing`，空才下单；重复下单静默丢弃、拿不到码 | api.md §2.2 + §2.2 末段 + 错误码表（无「产线忙」码） |
| 同格竞争 `(tick + playerIndex) mod 4` 值大者先动（已定机制）；先手随 tick 轮转，不写只有某座位成立的分支 | rules.md §3、§3.1 |

基座里没有一条硬约束是终稿之外自己加的，也没有一条终稿已定的事被写成假设。

### 3. 三支策略取向（最终措辞，等长、同详细度）

```
A 爆兵压制：优先把资源投进战斗单位，尽早争夺与压制点位。
B 扩张运营：优先占领资源点与扩张经济，攒够家底再转军事。
C 占点不采集：优先用占点扩张局面，不把产能放在采集这一侧。
```

方向性纪律仍随基座：不得违背上面的硬约束，也不得照抄文档里的读法与验收口径反推编排。
