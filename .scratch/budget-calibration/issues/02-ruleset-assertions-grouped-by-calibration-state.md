# 02: 规则集断言按标定状态分组(prefactor)

**What to build:** 默认测试里那条「未定键逐字等于各自的占位值」的断言不再硬编未定键的数量,改成**按标定状态分组**:未定键取各自标定的占位值、定稿键取终值抄本;键数不变量保留。

**为什么是 prefactor:** 八个键要分三批落定稿,而现断言硬编「未定键数 = 8」。不先改,后面三个落值票会各红一次,而且红的理由与本票的真正改动无关——那是最糟的一种红。

**判据仍是状态,不是值:** 文件里本来就有一个**真的取 0 的定稿键**,所以判据必须是标定状态字段,不能退化成「值是不是 0」。这一点在本票里不能被削弱。

判据见 spec 的 Implementation Decisions 第 8 条(落库形态)与第 9 条(连带对账)。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 未定键与定稿键各自按标定状态断言;判据是状态,不是「值是不是 0」
- [ ] 键数不变量保留(定稿键数 + 未定键数 = 键总数)
- [ ] 把任一未定键临时切成定稿,断言会要求它取终值而不是占位值(反向用例)
- [ ] 默认 `test` 全绿
