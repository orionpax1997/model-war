# 03: 枚举器扩展——组合 × 地图 × 种子 × 座位

- [ ] `C(4, N)` 组合数正确;`M×K ≡ 0 (mod 4)` 时**每个座位的对局数精确相等**;不满足时报错而非静默偏移。
