# 03: A 舱盲写端到端,打通管线并产出第一份 0 轮通过的基准脚本

**What to build:** 复用库内那套终稿盲写资产跑通一整舱 —— 模型仅凭 `docs/rules-v1/rules.md` 与 `api.md` 逐字全文盲写一份「爆兵压制」基准脚本,0 轮回喂直交,过静态校验器的 freeze 阶段。**这一票是 tracer bullet**:后面两舱与全部真引擎复验都吃这条管线(隔离舱搭建 → 静态校验 → 编译 → 入库),所以它验的是管线本身,不是一份脚本。口径与取舍见 spec 的 Implementation Decisions 第 3、4 条与 Testing Decisions。

要点:产物先落本工作目录下的盲写舱,**这一票不替换 `benchmarks/`**(整体替换在 04,避免目录里新旧混在一处而读数不可互比)。主指标是 **0 轮通过率**,回喂轮次另记一栏——回喂能把猜错机制的脚本救回来这件事至今没被测量过。

**Blocked by:** 02(契约面必须全部落库后再开舱;拿半成品契约去盲写,「契约自包含」这个结论不成立)
