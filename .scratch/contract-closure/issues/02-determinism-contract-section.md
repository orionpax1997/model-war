## Answer

**交付:** `docs/rules-v1/rules.md` §9 占位换成「禁止 / 保证」两栏对照表,每行带 § 指针,只收引擎裁决行为——单格竞争与轮转先手(§3/§3.1)、占领进度保留不动(§5)、同 tick 攻击同时结算(§6.2)、胜负判定链与名次(§7.2/§7.3)、失控丢意图与异常轨(§8.1/§8.2)、墙钟只观测、回放/观测边界。`api.md` 已有的可见面禁令(模块语法 / 动态求值 / 裸脚本、非确定源与宿主桥、座位自认、每单位每 tick 一条意图、跨 tick 只存数值、`typeof` 判别错误码)一条不抄,全部写成指向 `api.md` §1 / §2.3 的指针。表头明写分家判据:运行时可见面 vs 引擎裁决结果。

**关键落点:** `docs/rules-v1/rules.md:266`(§9)。

**实测/证据:** `pnpm run check:quick` 与默认 `pnpm run test` 全绿;散文里参数一律只写键名 + 指针到 §10,无「键名 + 数字」形态(散文门禁判红项不命中)。
