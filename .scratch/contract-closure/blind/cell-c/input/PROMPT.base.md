[粘贴 `docs/rules-v1/rules.md` 与 `docs/rules-v1/api.md` 的全文，原样，不摘要]

你要交的是一份 TypeScript 源文件 `script.ts`：单文件自包含，顶层声明一个入口函数 `loop()`，
引擎每个 tick 调它一次，它这一 tick 提交的全部意图随即被收走。

你的策略取向：{策略取向}。方向性要求，不得违背下面的硬约束，也不得照抄文档里的读法与验收口径反推编排。

硬约束（违反即校验失败）：

- **形态**：整个文件就这一份。里面不许出现 `import` / `export` / `require`，也不许动态 `eval`。
- **入口**：顶层声明 `function loop()`，**返回类型可省略**（写不写都对，引擎不读它的返回值——
  要交出去的是调动作函数提交的那些意图）。
- **可见面**：只调 `api.md` 第 3 节 API 表里那些名字，加上标准 ECMAScript 的纯函数。
  `Date` / `Math.random` / `performance` / `queueMicrotask` 这四个名字不可用，`__` 前缀的全局
  （宿主注入的桥）也不可用；沙箱里没有定时器、没有 I/O、没有别的宿主能力。调一个不存在或已删的
  名字按异常处理：该 tick 你提交的全部意图置空、记一次异常，累计到 `exceptionTickLimit` 就判负出局。
- **全整数运算**：坐标、id、tick、距离、携带量、资源数全是整数。别为了「保险」套一层 `Math.floor`，
  更别引入浮点中间量。
- **座位**：`getMyIndex()` 是取 index 的**唯一入口**（返回 `0|1|2|3`，整局不变，读一次存进模块级
  变量即可）。快照里没有 `you`、也没有 `isSelf`，**不要靠单位位置反推座位**——四方对称开局，
  那样反推出的四家会算出同一个号。`ERR_NOT_OWNER` 答的是「这个 id 归不归我」，不是「我是谁」。
- **跨 tick 记忆**：模块级变量跨 tick 保留，里面只放数值（id、坐标、tick、计数）与你自己算出来的
  东西。**不缓存对象引用，不缓存查询结果**——查询函数返回的都只是本 tick 的快照副本，下一 tick
  世界已经变了；下一 tick 要用，就下一 tick 再查一次。
- **错误判别只有两步**：`isError(result)` 判这次调用是不是错了，`errCode(result)` 取回 `ERR_*` 码。
  **不许用 `typeof`，不许用真值去猜**返回值长什么样。
- **每单位每 tick 只写一条单位级意图**：`move` / `moveTo` / `attack` / `harvest` / `transfer` 里
  最多调一次（`spawnUnit` 是玩家级意图，不受这条约束）。同一 tick 想做两件事（走一步再攻击），
  先想清楚哪一个更重要，只提交那一个。
- **先读队列，空才下单**：下单前先读那个基地的 `producing`，非 `null` 就别下这一单。
  已有订单时重复下单被静默丢弃——不扣款、不计异常、队列不变，也拿不到任何错误码（错误码表里
  没有「产线忙」这一码）。
- **轮转不是「永远后手」**：同格竞争按 `(tick + playerIndex) mod 4` 排序、**值大者先动**，这是已定
  机制，不是假设。先手随 tick 轮转——不要写只有某个座位才成立的分支，也不要按「我先手 / 我后手」
  分两套策略。

输出：单个代码块，放 `script.ts` 的脚本全文（完整可运行，不给片段、不给省略号）。
无对战反馈；只有静态校验错误会回喂（≤5 轮）。
