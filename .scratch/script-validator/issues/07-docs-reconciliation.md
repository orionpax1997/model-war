# 07: hld 文档收口

**What to build:** 把本 feature 的承载权转移写回它唯一该待的地方:hld。核心是**两类规则从静态校验器移给了编译器**——这不是实现细节,而是一次承载权的转移,不改文档的话后来者会去找一条不存在的白名单规则,或者看到解析器有 AST 就以为能自己写一条。

**Blocked by:** 01 禁列规则端到端 + 校验器入口, 02 模块系统规则, 03 宿主桥前缀规则 + 注入面一致性断言, 04 脚本体积规则, 05 内置全局白名单的收录判据与表回填
