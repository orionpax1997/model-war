# 05: 内置全局白名单的收录判据与表回填

**What to build:** 真源包里那张现在为空的**内置全局白名单**拿到一条可判的收录判据,并据此回填。判据是「无副作用、不读这个 VM 之外的任何状态」——它一句话对所有内置全局一视同仁,且与禁列构成一对方向相反的判据:禁列是「一律禁」(不可复算),白名单是「一律收」(不越界)。这张表不再被静态校验器的任何规则消费(白名单反转已由编译器执行),它喂的是面向模型的规则文档里的内置全局表。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 收录判据**写成一条可判的陈述**,不是「纯函数子集」这种方向性描述;判据进 hld 的规则表
- [ ] 判据的**两个方向**都验过:一张现有的内建全局被收(`JSON` / `Object` / `Array` / `Map` / `Set` / `Number` / `String` / `Math`),一张被拒(`Date` / `performance` / `Math.random`——后两者与禁列同向,判据要给出与禁列一致的理由)
- [ ] 表按判据回填;**不写「分叉容忍条款」**——判据一旦确立就没有分叉,因而没有条款
- [ ] 回填的每个名字在头注里带一句**为什么收**(判据的实例),让人能一眼看出加名字的门槛
- [ ] 与禁列的一致性:任何出现在禁列表里的名字**不得**出现在这张表里,落成一条机器断言(两表相交的失败模式正是「白名单放行了禁列」)
- [ ] 显式记下:这张表**不参与**白名单反转的判定(那一侧是编译器的名字解析),它的消费者是规则文档的生成;两者不得互相引用为「依据」
