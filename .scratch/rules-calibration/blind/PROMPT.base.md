# 盲写 prompt 基座（冻结模板，A/B/C 只换一行策略取向）

> 用法：原样粘贴 + `draft/` 四文件全文（不摘要、不解释）。
> 禁止追加 gdd/hld/实现/桩源码/工作台结论。违禁即污染。
> `{策略取向}` 只换一行，三支等长、同详细度。

---

你为四方 RTS 对局（1v1v1v1，tick 制）写参赛脚本。
输入只有附件 4 份文档（`README.md` / `rules.md` / `api.md` / `wording-risks.md` 不读——只读前三份全文，
`wording-risks.md` 是否附带见本次任务说明，二者选一后三支保持一致）：
[粘贴 draft/ 四文件全文，原样，不摘要]

你的策略取向：{策略取向}。方向性要求，不得违背文档硬约束，不得照抄附录 C1~C7 反推编排。

硬约束（违反即校验失败）：

- 单文件自包含，顶层 `function loop(): void`，无 `export/import/require/eval`；
- 全整数运算；禁 `Date` / `Math.random` / `performance` / `queueMicrotask` / 定时器 / `__*` 全局；
- 只调 `api.md` 的查询/action 函数；跨 tick 只存数值 id 和模块级变量，不缓存对象引用；
- 每 tick 只读快照，不另行告知你的 index——从快照认出自己
  （二选一：候选 A 容器顺序 / 候选 B 自标记，见 `api.md` §5），记下你选了哪个；
- 轮转优先按"值大者胜"假设写（待终稿确认，见 `rules.md` §3），记下该假设；
- 同单位一 tick 只写最终意图（后写覆盖先写）。

输出：单个代码块放脚本全文 + 两行记录（选了哪种自认候选；对轮转方向的假设）。
无对战反馈；只有静态校验错误会回喂（≤5 轮）。

---

策略取向三档（每次只取一行填入）：

- A 爆兵压制：优先生产战斗单位，尽早争夺与压制。
- B 扩张运营：优先占领资源点与扩张经济，再转军事。
- C 农民海（可选）：以农民为主力占领/堵点，检验占领张力。
