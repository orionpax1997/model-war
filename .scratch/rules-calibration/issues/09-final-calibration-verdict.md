### 0. 收口判据(本票采用的口径)

**数值项必须有终值且 gdd 表述与终值自洽;设计意图类命题允许“记录为有意决定 / 已知缺口”并改写 gdd,每条记录带复验条件与回流触发;gdd §7 中本图不拥有的键以移交指针计清零。**

选这条而非“全绿”的理由:典型经济与拉满经济的吞吐差 4.4×(典型整局消耗 ≈440,拉满 ≈1920),**没有任何单一储量能让两者都在 400–600 枯竭**——“枯竭必须是典型阶段”这个命题在当前吞吐分布下无解。

### 2. 失衡项的裁决(本票唯一改值的地方)

**`resourcePerSite`:125 → 200**(全图储量 2000 → 3200)。依据:让拉满经济剖面的枯竭落在 400–600 内(旧值 315),而典型经济仍不枯竭(消耗率 21.8% → 19.9%)——把"惩罚提前 185 tick"换成"典型局不触发、极端局在窗口中段触发",配合 §2 改写后自洽,且**不动 C7 与票 05 的任何判读**。**复跑实测:拉满经济 470–550、全矩阵采空中位 511、典型局结束时剩 80.1%——终值成立。**

- 连带:票 03 的验收剖面(`W=8` / `η=0.5` 推“tick 500 采空”)作废,替换命题见 gdd §8 记录 #8(拉满经济 400–600 枯竭 / 典型经济消耗 ≤ 总储量 1/4 / 地图改 N 不得改节奏)。票 03 Answer 已加一行修正指针,原始决策痕迹保留。
- 连带:gdd §2 表格最后一行改为条件性表述 + 表下加“证据校准注”,“随 `tickLimit` 缩放”的口径保留。

**不成立项的其余三条**不调参、不加机制,落 gdd §8 记录 #9(终局形态:接受 + 不为超时率调分权重)、#10(骑兵闲置 + R2 唯一解缺口)、#7(枯竭定位)。**不开 §6.1 的“约束不成立”记录**——七条 C 约束在终值下零违反,不成立的是*时间轴形态*而非*约束*。

### 3. 桩的夹具解读 → 升格为规则定案

三条原本只是 throwaway 假设、却是全部经济判读的承重墙,已收编进 gdd 与契约:

1. **开局资源点归属**:每方开局恰好拥有家附近最近一圈资源点(数量为 4 的倍数,四重对称)→ 写入 gdd §4 点位表不变量;同时消解 gdd §5 “起始资金+起始农民保证开局可补经济”与“须先占领才有开采权”的自相矛盾。`ruleset` **不新增键**(属地图不变量,map-lint 断言)。
2. **出兵格 = 基地格本身**:写入 gdd §5,并显式声明**自家单位堵自家基地会阻塞自己的产线**(堵点战术的自限成本)。
3. **同一产线重复下单静默丢弃、不扣款、不计异常**:写入 gdd §5 + 契约;同时契约快照补 `sites[i].producing = {type, remainingTicks}`,否则 69% 拒单率是契约缺陷而非设计。

### 5. 契约定稿措辞(裁决)

- **座位自认(已证实 P0)**:`getMyIndex()` 作**唯一正式入口**(不往快照塞自指字段,hld #6 的拷贝粒度还是开放项);`ERR_NOT_OWNER` 的语义(对非己方单位返回、沙箱内即时返回)钉进错误码表,但**不**写成“可以这样反推座位”——08 证明它可行而 4 舱发现率 0/4,写成攻略等于鼓励行为探测。
- **API 可读面**:`ErrResult` 必须有显式判别式(`isError(r)` / `errCode(r)` + 可运行示例,不许模型用 `typeof`/真值猜);快照补 `players[i].{resources, alive, exceptionTicks}` 与 `sites[i].producing`;`ERR_*` 全表以 `schema` 生成为准并定名。
- **文案层**:轮转方向**定死“值大者胜”**并删掉草案的“方向为假设”TODO,保留“先手随 tick 轮转,不要赌先手”;“先占矿才能采”补上“开局你已拥有家附近一圈资源点”;P0-3/5/8 实测无卡点,维持现措辞;P0-6 因判别式重写对照表;P0-7 只写人话(“异常不清记忆、不重建 VM;仅引擎级故障会重建”),WASM trap 术语只留在 gdd 侧对回放 events 流;P2-14 补一句“有效 = 站在己方资源点相邻格且携带未满”。
- **《异常与出局》披露三层**:必知(超预算/异常 → 本 tick intents 全部丢弃 + 计数;累计 `exceptionTickLimit` → 判负出局)/ 建议知(不清记忆、不重建)/ 不披露(事件计数每 5000 一格、内存读数口径、墙钟只观测——只写“每 tick 有计算预算上限”)。
- 采纳 gdd 改字建议 G1 / G2 / G3。

### 6. 预算类参数:只定存在与量纲(Q5)
