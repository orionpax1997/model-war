# 06: 复验 gdd #8 两条等效命题 + 裁决 gdd #6 / 定 K

**What to build:** 用带墙的真地图把规则标定环那两条**从未在真图上验过**的等效命题跑一遍，并关掉 gdd §8 的两条开放项（#2 地图坐标、#6 变体是否参与策略决策），顺带把种子数 K 定下来。

这两条命题此前是在**全平原夹具**上验的，而规则明写「机动价值靠地图形状与速度差体现」——墙一加，采集吞吐下降，枯竭时点**推后**。所以「三张真图上枯竭仍落在 400–600」是本 feature 最贵的一条验收，也是唯一一条能把地图设计与规则数值绑在一起的验收。

**Blocked by:** 05（三张地图落库）

**Status:** ready-for-agent

- [ ] **命题①**：三张图各自跑桩，拉满经济剖面（每家 6–8 专职农）的采空中位**都落进 tick 400–600**
- [ ] **命题②**：典型经济（4 份基准脚本的实测吞吐，整局约 440）消耗**不超过总储量的 1/4**
- [ ] 桩的跑法与标定环**同源**（复用标定环留下的桩与同一套变体填充机制），数字才可比
- [ ] **不许沿用无墙夹具的数字**。原型阶段的估算是「基线 479 + 绕路影响」的推导，实跑是本票的事
- [ ] 命题①不过时**返工改图**而不是放宽窗口：迭代到满足口径为止，**不设轮次上限**（设上限等于允许交出一张明知不合口径的地图）
- [ ] 返工的触发条件写明：矿路被墙拉过 `d = 10`（`d=11` 起枯竭顶破 600），或全图路径拉伸把吞吐压到 600 tick 之外
- [ ] **gdd #6 裁决**：地图变体是纯装饰性微扰、**不参与策略决策**。依据连同量级一起落进文档：静态候选 8 条轨道 / 32 格 = 全图 0.781%、一格不压点位及其八邻域、1336 场里无任何记录提到变体有影响
- [ ] **K = 4**。推导链完整落文档：变体纯装饰 → 多种子不产生新信息 → K 唯一作用变成座位均摊（要求 `M × K ≡ 0 (mod 4)`，M=3 故 K 取 4 的倍数）→ 最小值 4
- [ ] 变体裁决的落点是 **gdd §8 #6 那条记录**（带指针），**不改 fsr**——按文档分工 fsr 是风险与估算的家，而这是规则侧裁决的回流
- [ ] **gdd §8 #2 标为已收口**，带坐标来源与「点位布局三图共用」的结论
- [ ] 复验用的 4 份基准脚本**不进仓库测试**（沿用「一次性证据不是回归基线」的纪律），但它们是本票必须用的那四份
- [ ] 复验结论写进文档时**带上口径**：哪张图、什么规模、多少场、中位与分位，不写单点数字
- [ ] 若实跑发现与原型估算**不一致**（例如三图的枯竭中位明显分叉），记录差异并查因，**不调整估算模型去凑**——估算是探针，实跑是证据
