# 03: 生成器与允许名单退役

**What to build:** 改真源包里的内置全局白名单 → 跑生成器 → 工具包规则层的行为随之变,禁浮点门禁仍然绿。生成器代码落在工具包,它 import 真源包;工具包的规则层则读生成出来的源文件,以保住快门禁「零构建」的性质。生成器持有一张生成物注册表,每件 = 标识、产出位置、生产函数——本票只注册一件。工具包里那张手写的允许名单就此退役,不留副本。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [ ] 工具包**正式声明**真源包为依赖并加 project reference,生成器直接 import 它(它指向依赖图的根,方向合法)
- [ ] 生成器持有一张**生成物注册表**:每件 = 标识、产出位置、生产函数;新增生成物是往表里加一行,不是改骨架
- [ ] 内置全局白名单的真源迁到真源包:整数闭包判据下的 `Math` 成员表,以及其余内置全局名

- [ ] 生成出来的源文件带**生成头注释**:由谁生成、勿手改
