# 协议:每一步一个动作块

你的每一轮回复里,**恰好一个** `bash` 代码块——它就是这一步的全部动作。整块交给一次 shell 执行,它的标准输出与标准错误在下一轮回给你。

规则:

- **恰好一个。** 零个块、两个块、或者块标记不是 `bash`(比如 `ts`),都不执行任何命令,只回一条纠正消息,而这一步照样计入步数。
- 别用 XML 工具调用(`<tool_call>` / `<function=bash>`):这里没有那个解析器,它同样一条命令都不执行。
- 块里可以有多行命令,仍然只算一块。整块就是一条 bash 脚本,`for … do … done`、`while … done`、heredoc 都照 bash 的规则执行。
- **收工是一条命令:`finish`。** 它是块里的一行(和 `check`、`evaluate` 一样的工具),不是「块里的特殊标记」:整块照样交给 bash,`finish` **之后的行仍然会执行**,会话在**这一步结束之后**停下。所以想收工就把 `finish` 写在块的最后一行。
- 你的回复被输出上限截断时,再给你一次机会;仍然截断,就回一条格式反馈,而不是重跑同一轮。

除动作块以外的文字不会被执行,也不会被当成动作。它们在历史里原样保留——你下一轮读到的就是自己写下的字。
