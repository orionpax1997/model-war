## 3. 移动与碰撞

- **一轮移动结算只以该轮开始时的占位为准**:单位离开本轮所在格,不使该格对后来者可进入;
  同一格至多一个单位成功进入。
- **同格竞争**:多方目标格相同 → 算出每个竞争者的**轮转优先值** `(tick + playerIndex) mod 4`,
  按这个值排序,**值大者胜**;落败者原地不动,不尝试次优目标格。四个玩家的轮转优先值互不相同,
  所以这一层不会有平手。`tick` 是正在结算的这一 tick,`playerIndex` 是你的座位号(取值见
  [`api.md`](./api.md) 的 `getMyIndex()`)。
- **交换与穿行**(A 要去 B 所在格、B 同时要去 A 所在格)与**链式移动**(A 要去 B 所在格、B 同时要去
  C 所在格):按本轮开始时的占位,B 格本轮被占,故 A 失败;B 能否进入 C 格只看 C 那一格自己的竞争,
  与 A 无关。二者互不牵连,没有链式裁决,也没有环形追逐。
- **己方单位之间同样按这套裁决**:没有友军穿越,自己人也会互相挡路。
- **`moveTo`**:引擎每 tick 沿寻路结果走一步,等价于本 tick 的 `move`,参与同一套裁决。路径不跨
  tick 缓存,每 tick 重算。
- **骑兵的二次移动**:重复整轮结算一次——第一轮结算后的占位就是第二轮的基准,两轮里的 `tick` 值
  相同(轮转优先不因多走一步而重排)。

### 3.1 先后手:轮转不是「永远后手」

- 轮转优先的算法只有一条:同格竞争时算 `(tick + playerIndex) mod 4`,**值大者先动**。`tick` 逐 tick
  加一,`playerIndex` 固定,所以你的优先值每四 tick 绕满一圈。
- 由此可得偏置的形状:座位号相差 d 的两方中,**座位号大的那一方**在 `(4−d)/4` 的 tick 里先动,
  **座位号小的那一方**在 `d/4` 的 tick 里先动。两个数都大于零——座位相邻时是三比一,座位相对时
  是一比一。
- 因此**没有任何一方是永远后手**:轮转说的是优先权逐 tick 换人,不是「你的座位固定吃亏」。真正
  存在的只是**比例**上的偏置,而它由座位在赛季内轮换摊平,不由你在脚本里补偿。
- 结论:**先手随 tick 轮转,不要赌先手**。不要写只有某个座位才成立的分支,也不要按「我先手 /
  我后手」分两套策略。

示例(3×3 坐标系,无地图假设;`(tick+index) mod 4` 值大者胜):

- 同格竞争:A(0,0)→(1,1)、B(2,2)→(1,1),(1,1) 空 → 轮转优先值大的一方进入,另一方原地。
- 交换穿行:A(0,0)→(1,0)、B(1,0)→(0,0) → 两者都失败(目标格本轮被占),均原地。
- 链式移动:A(0,0)→(1,0)、B(1,0)→(2,0),(2,0) 空 → A 失败((1,0) 本轮被占),B 能否进入 (2,0)
  只看 (2,0) 自己的竞争,与 A 无关。

## 4. 经济与生产

四方对局里没有被动收入:资源只从**采集**来,一切扩张都要先有资源。

### 4.1 采集与交付

```
采集: 农民站在己方资源点的相邻格上即开采,每个 tick 得 harvestRate 资源(射程见 §10 的 worker.range)
携带: 携带量上限 carryLimit;满载一次需要 ⌈carryLimit ÷ harvestRate⌉ 个有效采集 tick,满即停
交付: 走到己方控制基地的相邻格,调 transfer(射程见 §10 的 worker.range),一次交出全部携带量
      同时相邻多个己方基地时,交付给数值 id 最小的那个
归属: 资源进玩家全局共享池,无上限,不按基地分池
```

- **一个「有效采集 tick」= 满足全部三条的那个 tick**:农民**站在己方控制的资源点的相邻格**上、
  **携带量还没满**、该 tick 的结算确实结算到了它。站在中立资源点旁边不采集;站在己方基地旁边不
  采集;携带满了之后原地不动也不再计数。所以「一次满载」的时间是把往返的路程算进去之后的时间,
  不是满载所需 tick 数本身——地图上家与矿的距离直接决定你的经济节奏。
- **资源点**:开局时**你已经拥有家附近最近的一圈资源点**(数量为 4 的倍数、四方四重对称;具体
  布局与数量由地图数据声明,见 §1),可以直接开采。其余资源点**中立,必须先完成占领才有开采权**
  ——占领进度机的规则见 §5,占领一个点位所需的累积 tick 见 §10 数值表的 `captureTicks`。
  「先占矿才能采」只对中立资源点成立,不是开局条件。
- 每个资源点有**有限储量**(`resourcePerSite`,见 §10 数值表):采空之后**点位不会被移除**,它仍然
  计入胜利条件,只是再也产不出资源。矿采完不能续,所以开局占下多少矿是这局经济上限的一部分。

### 4.2 为什么采集与产能的取值是这样定的

单基地满产的烧钱率(§10 派生量表里的 `FULL_PRODUCTION_COST_RATE`)与**单农收入**
(§10 数值表的 `harvestRate` ÷ `carryLimit`,即一个农民跑一趟的净产出)之间必须留出一个明确的
倍数关系:**满产消耗要显著高于单农收入**。这个比值就是这两个数为什么定在这里的理由——比值太小,
「只开矿不扩产」与「只扩产不开矿」两条路都能赢,经济不再是决策;比值太大,产能完全压过采集,
采矿与护矿就退化成走过场。两个取值都在 §10 的表里,这里只留这条关系与它的指针(设计意图与
清零过程见 gdd §5《经济与生产》与 gdd §8 开放项 #5)。

### 4.3 经济死亡

- **无被动收入是刻意取舍**(不做死锁保护)。**经济死亡**:你没有任何农民单位,且 `resources`
  不足以再造一个农民(农民造价见 §10 数值表的 `worker.cost`)。这个状态**不可逆但不是出局**——
  占领资源点不会给你农民,没有被动收入,所以经济回不来。
- 但你**仍可用残兵抢点、阻断、拿下胜利**:占领不需要资源(见 §5),所以经济死亡之后
  对局照常继续。「翻盘」指整局仍可翻盘,不指经济可以复活。

### 4.4 生产

- 任何己方控制的基地都是**一条独立产线**(每基地一条队列,一次一个订单);多基地 = 并行产能。
  基地**不可摧毁、无攻击能力、无维修**;基地格可通行,且单格单单位。
- **下单即扣款**;资金不足时下单无效(`ERR_NOT_ENOUGH_RESOURCES`,错误码见
  [`api.md`](./api.md)),不占队列也不扣款。**同一条产线上已有订单时重复下单被静默丢弃**:
  不扣款、不计异常、队列不变——所以你可以每 tick 无脑重发生产请求,不必自己记队列。
- **出兵格就是基地格本身**。它被**任意单位占据(含你自己的单位)**时,该队列**挂起等待**;
  格子一空就**自动续出**,订单不会丢。所以**自家单位堵自家基地会阻塞自己的产线**——这是堵点
  战术的自限成本,不是 bug。
- **基地易主**时,该基地队列取消并**全额退款给原主**;原主已淘汰(基地回归中立)时**不退款**。

## 6. 战斗

### 6.1 兵种定位与设计约束

四种固定兵种,不可拼装。本节只说**每个兵种为什么长这样**;造价、生命、伤害、射程、速度、生产耗时
这六个取值一律见 §10 数值表的兵种属性表,本节一个字也不复述。下面的「约束」是**取值必须同时
满足的关系**,是给调参者的判据,不是脚本运行时要遵守或要检验的东西——脚本只管按 §10 的取值
写就行。

- **农民**(`worker`):经济与堵点。采集、携带、交付,**无攻击能力**。它是全图最脆弱也最高价值的
  目标,所以护矿是常态、敌方切农是最廉价的打击。它不加速任何机制,它的价值只在经济与堵点。
- **近战**(`melee`):正面战力与抗线的**性价比标杆**,射程只有相邻一格。要求:等成本的站桩对拼
  里它打得过远程与骑兵,且它的「每造价生命」与「每造价伤害」都是全兵种最高——使「数量 × 抗线」
  成为正面主策略,把战术差异让给机动与射程。
- **远程**(`ranged`):**阵地输出**,射程超出相邻一格且不随距离衰减,靠纵深与保护发挥。要求:
  近战贴脸后很快就能把它打死(它的生存期短到不足以当通用兵种),输出必须靠保护与纵深换来。
- **骑兵**(`cavalry`):**高机动**——袭扰、抢点、切农、直插后方。射程只有相邻一格,速度是其余
  兵种的两倍,造价不低于近战的两倍。要求:等成本的站桩对拼里它打不过近战与远程——**它的价值
  全部来自速度,不值在正面**,必须贵到不能当主力。

### 6.2 战斗结算

- **同 tick 的全部攻击同时结算**(批处理,没有先手秒杀):先一次性算出本 tick 的全部伤害,再统一
  扣血。**攻击者本 tick 死亡不影响它的攻击生效**。
- 伤害进**单一血池**扣减,归零即死;无护甲、无技能、无冷却。是否命中没有任何随机成分(对局内
  没有随机源,见 §9)。
- **目标不可为基地**(基地不可摧毁)。`attack` 的目标必须是敌方单位,**任意兵种都可被攻击,
  含农民**。**无攻击能力单位**(农民)的 `attack` 无效:丢弃,不扣资源、不计异常。
- 伤害、射程、速度的取值见 §10 数值表的兵种属性表。
