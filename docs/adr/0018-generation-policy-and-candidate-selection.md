# 规范生成意图与完整候选选拔分开审计

强制采样参数并不能保证不同模型拥有等价的推理/代码预算,中转接受字段也不证明上游身份或实际执行。决定保留当前名册和渠道,以 `models.yaml` 的规范政策分别表达生成意图、官方与渠道支持证据;未知能力如实保留,不隐式探测或换路由。接受部分条件仍不可认证的限制,换取可审查的请求证据,不将未知用量记零或把重叠 token 字段当账单。

统一事实优化后直接定版最后有效阶段,会丢弃本轮已合法产生的较好中间候选;使用优化读数挑选则复用了已回喂的信息。决定显式启用独立有效候选选拔:完成全部约定阶段后,使用预定相同条件下的完整终局积分确定冻结身份,不新增模型改写、不回喂选拔结果。接受额外本地对局和候选证据存储成本,换取可复算且与正式评测隔离的选择;选拔不完整时整次生成失败,避免缺场分母造成选择偏置。

最后有效阶段保留原生成身份,选拔胜者可以来自较早阶段;实际冻结脚本复制胜者的原始源码与编译字节。相同编译产物可以复用同一计划的完整结果,阶段、源码与协议轮仍分别保存。这个决定局部演进 [ADR-0017](./0017-uniform-two-fact-feedback.md) 的定版关系,不改变事实优化机会和反馈边界;未启用选拔及没有选择记录的历史档继续沿用原关系,不迁移历史产物。

公开生成报告采用读取端明确白名单,因为旧日志、失败原文与未来 provider 返回值不能靠写出侧安全性担保。接受公开摘要缺少自由文本诊断与未知停止原值的代价,仅披露身份、固定状态/数字及覆盖范围;私有原始旁证仍保留。需求与验收归 [SRS](../srs.md),比较约束归 [GDD §3.3](../gdd.md),执行计划、预算、数据身份和启动说明归 [HLD §6.3/§7.4/§9](../hld.md),术语归根 CONTEXT。
