# 行动事实沿现有桥采集,以完整性约束回喂

ADR-0015 的“得分来源快照差分触发、最多一次机会、共用总轮数上限”边界已由 [ADR-0017](./0017-uniform-two-fact-feedback.md) 局部取代;当前机会分配与轮数口径见该决定及 hld §6.2。本决定的行动事实采集、投影、完整性与身份校验边界继续有效。得分来源快照差分有末 tick 与异常淘汰缺口,无法区分行动尝试、即时错误与实际结算。补充行动事实因此将固定调用/公开错误码计数与宿主结算效果独立命名;效果取实际成功 apply,而不从快照或 `calls-errors` 推导成功。移动后死亡不撤销已移动格数,生产订单开始不等于生产完成。

选择在 runtime 内部直接递增固定私有计数,随现有 setSnapshot 清零、drain 返回,而不是包装用户脚本、添加桥或逐动作跨宿主调用。它保持既有边界并覆盖真实入口的早退,但带来真实 guest/host 开销;新开销纳入原事件/内存计量,原预算阈值不改,重建 runtime 并复核受影响的 runtime/预算门禁。宿主效果采集开/关必须保持相同回放、hash 与判定,不把旧实验读数变成规则或宣称新旧 runtime 计量逐字相同。

事件截停、未吞异常与其他未返回载荷的 tick 不再执行 guest 补 drain,只记缺失覆盖。这样避免为了观测继续运行已截停代码;代价是不完整行动计数不得进入模型,只陈述原快照读数与覆盖缺失,缺失不等于零。覆盖仅统计候选实际被调度的执行 tick,淘汰后未调度不算缺失。旧四栏继续兼容读取;旧“仅全零时回喂”文案与观测缺失时的 opt-in 收口服从 ADR-0017 和 hld §6.2,不得误称完成统一优化。损坏与 hash/seed/seat 归属违约仍是严格协议错误。对局事实绑定实际编译 JS,每轮 opt-in 候选保留不覆盖的 JS 旁挂供重跑;该来源字节保存失败或撞名时停止生成,避免无法重放或旧证据混入新候选。最终 JSONL 沿兼容路径发布,发布失败仍只警告。

反馈仍默认关闭,不改变游戏淘汰条件;开启后的优化机会与诊断修复预算见 ADR-0017。投影只含逐对局固定调用数、公开错误码和独立效果,明示快照与结算区别;hash 留归档侧,不追加参数、坐标、异常诊断或因果策略建议。数据形状与持久化/读取机制的唯一家分别为 schema 与 hld §5.1、§6.2、§7.4。

试跑 JSONL 在 CLI、gen 与报告三个读入点都需校验,但字段形状只有 schema 一个家。各消费者从共享 JSON Schema 派生验证器,身份/跨行和短计数关系在读入端校验;不手写第二份字段表、类型或范围。AJV 实例仍只在 CLI,gen 的窄子集适配器遇到未支持关键字大声失败,不扩大 schema 的运行时职责。这一补充澄清 ADR-0003 的单入口措辞,避免为读取私有旁证反向依赖 CLI。

本次 runtime 变更按 ADR-0009 的终值失效纪律实际运行完整预算复核。初版新增常驻开销曾使推导越档,先收敛 runtime 构建开销后再完整复核,探针、基准和终值推导全部通过;没有就地放宽终值。预算复核红时暂停收口,先排除运行时回归,若最终 runtime 仍红则另开重标节点;本次最终复核绿,无需改规则值。历史 archive 的 runtime hash 不追填,重放继续使用对应历史字节。
