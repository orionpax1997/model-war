# 选拔决胜更新与历史身份兼容

选拔决胜政策更新的规则真源为 [gdd §3.3](../gdd.md#33-公平性)。既有归档已冻结原始 TS/JS 和阶段身份,重新应用当前决胜规则会使历史证据与冻结身份失配,因此保留 ADR-0018 作为历史决策,不重写既有档案。

数据版本保持不变,由 `earlier-stage` 明确标识历史决胜语义,公共读取器按原算法完整复算其证据、胜者与理由;新生成的 CLI 校验拒绝这一历史理由。当前结果使用 `later-stage` 表达阶段决胜,唯高分结果仍使用 `highest-average-points`。这使旧档继续可审计,同时防止兼容路径替代当前生产规则;数据与消费者边界归 [hld §6.3](../hld.md#63-独立有效候选选拔)。
