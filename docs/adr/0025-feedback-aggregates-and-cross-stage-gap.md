# 事实回喂分三层:聚合对差表、逐场一行、最差三场展开

事实回喂原先按「每场三栏全展开」组织:每一场都把四方的计分依据、行动调用数与结算效果摊开写一遍。场次少的时候这是最直接的写法——读者拿到的就是全部事实。但它不随场次规模伸缩:一旦一次评测变成整张网格(维度见 [ADR-0024](./0024-single-evaluation-grid-and-selection-as-recompute.md)),逐场全展开会把提示顶到一个数量级以上,而模型能读到的信息反而更少——单局的琐碎细节淹掉了「哪个座位、哪张图稳定地差」这一层。

决定把回喂改成三层,次序固定:

1. **对差表**:按座位 × 地图聚合。每格给候选的平均名次、平均名次积分、平均领土分与第一名分差、末位局数,再给**与上一阶段同一格的变化**(Δ 平均名次积分 / Δ 分差,Δ 定义为本阶段减上一阶段)。第一阶段没有上一阶段,如实写「无上一阶段」,不拿别的阶段充数。
2. **逐场一行**:图、候选座位、组合(该场轮空的是哪一位对手)、候选名次、四方领土分、结束原因。一行一场,只给读得下去的量。
3. **最差三场**:只对这三场展开原有的三栏明细(行动调用数与即时错误码、独立结算效果、终局事实)。排序口径必须确定:候选名次积分升序 → 候选领土分升序 → 场次升序,同一组观测渲染两遍逐字相同。

三层的分工是「聚合优先、明细补足」。聚合表回答「稳定差在哪」,这是逐场细节永远答不出来的;逐场一行保证每一场都可被点名、可被追问;最差三场回答「哪一局崩了、怎么崩的」,这是聚合必然抹掉的形态。取最差而不是最好,是因为可修的东西在失败局面里;终局未知的场次不进排序,也不当作零分,三席不满时按场次补足——「未知」仍然展开成「终局成绩未知」,而不是从表里消失。

**跨阶段对差是这次最便宜的新信息**。模型要回答的是「我这一改有没有用」,而这个答案只需要两阶段同一格的数字相减:不需要新对局,也不需要任何因果推断。同一张计划内的相邻阶段才写 Δ;计划不同源就不写,不跨计划拼数字。

体积是判据不是愿望:**反馈总量不随场次线性膨胀,并守住一条上限**。上限的具体取值与当前体积都由测试盯着,不写进本文;证不出上限就是违规。这条约束的意义在于:它逼着新增信息进聚合维度,而不是回到「再加几场明细」。

被否的方案:

- **继续逐场全展开**:场次翻一个数量级,提示长度同倍涨,信噪比与缓存命中一起掉;模型读到的事实变多、可用的判断变少。长度不是中立的——它自己会改变结论。
- **只留最差三场**:没有趋势。三场明细能说「这一局崩了」,说不出「这个座位是不是每局都差」;把聚合砍掉,等于把唯一的横向视角换成三个孤立现场。
- **给因果结论与策略建议**:那等于把「这份脚本为什么输」写成模型的答案。反馈一旦掺进判断,失败就无法区分是模型的判断错还是反馈的判断错,而且不同对手、不同地图下的建议会互相打架;而回喂文本又必须能被观测重建——因果结论重建不出来。

长期约束:三层结构与「聚合优先、明细补足」的次序不变;新增维度只能加进聚合表,不得退回逐场全展开。缺失不补零、覆盖缺失单独说明(读数少于计划场数时,格的均值只按已知局算并标出已知几局;行动事实的**全网格**覆盖——完整 / 缺失 / 不完整各多少场,缺口点名场次——也在这句声明里说,不许只把最差三场当有缺口的场次)。三层之前另有一行**陪练池身份**(角色、`role:slug`、装载来源,代位时明写「本阶段以 X 代位」),它是「跟谁打」的唯一出处,不算第四层。候选与该场某位对手字节相同时,逐场一行加一句「本场对手与你字节相同」——镜像局照跑,但读者必须能在这一场上认出来。最差三场的排序必须是确定性的,同一组观测重渲染逐字相同。全文只给事实,不出现因果结论、策略建议或「应该 / 建议」这类措辞,并有断言盯着。跨阶段对差只在同一张计划内比较。反馈里的分数是**生成阶段分数**:不是赛季成绩,也不是选拔复算读数。

与既有 ADR 的关系:本文**演进** [ADR-0017](./0017-uniform-two-fact-feedback.md) 的统一回喂与 [ADR-0019](./0019-terminal-match-facts-feedback.md) 纳入真实终局事实的内容边界——它们决定**回喂什么**,本文只改**怎么摆**,两者对「行动事实 / 终局事实」的定义与完整性判据继续沿用,投影边界仍归 ADR-0016。ADR-0019 的逐场全展开边界被本文收窄为「最差三场展开 + 其余一行」,索引标 partially superseded,其正文按该决定自己的规矩不改写。渲染仍是代码内拼接,反馈文案不引模板文件——内容真源是观测与计划,不是模板。

重新评估的条件:场次规模再上一个数量级(那时聚合维度可能要再收一层);观测发现模型只看最差三场而跳过聚合表(那时该减少层数,而不是增加);出现必须跨计划比较的趋势需求(那时要先有版本化的尺子,见 ADR-0024);或某类失败(例如座位导致的超时)在聚合表里仍然读不出来,那时该补的是聚合的维,不是明细的行。
