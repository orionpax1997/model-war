# 显式事实优化统一两轮,诊断修复按阶段独立计量

按无得分来源补救一次会使不同模型获得不同的策略改写机会,而快照零读数既不能证明策略失败,也不能证明没有实际行动。用户已批准 `--score-source-feedback` 开启后对所有模型统一两次自身事实回喂,形成三个有效候选;每阶段诊断修复统一沿用旧默认额度并独立计量,不受逐模型上限影响,保留初次与最终候选的分别报告,使初次生成能力与优化后表现可审计。

这局部取代 [ADR-0015](./0015-opt-in-score-source-feedback.md) 与 [ADR-0016](./0016-production-action-facts.md) 的“全零触发、最多一次、消耗原总轮数”边界。接受增加生成调用与候选证据保存成本,换取相同优化机会;默认仍关闭,未开启行为兼容,行动事实的采集、投影、完整性与身份校验继续沿用 ADR-0016。优化试跑与正式评测独立,正式结果不回喂,评测种子对全体统一且不得与优化种子重叠。

需求与验收归 [srs FR-5/FR-6/FR-7/FR-8/NFR-2](../srs.md),机会公平与优化/评测独立约束归 [gdd §3.3](../gdd.md),循环、计数与种子边界归 [hld §6.2/§7.4/§8.1](../hld.md)。跨进程候选保存与报告关联的具体接口归 hld §12 #12,本决定只记录机会公平与计量边界。
