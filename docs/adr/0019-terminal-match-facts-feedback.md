# 两次事实反馈纳入真实终局计分依据与四方结果

优化试跑执行完整对局,但行动调用、交付量与易主次数既不能还原终局控制权和存活兵力,也不足以解释胜负或判断候选整体表现。决定在原有两次自身事实反馈中同时提供行动事实与真实终局事实:保存四方各自的终局计分依据,并明确座位、身份、领土分、名次、名次积分、存活状态、淘汰时间及结束原因。选择真实终局结果,而非从累计过程读数或最后行动采样推断成绩;反馈保持统一、确定、可审计,不附因果结论或策略建议。

本决定局部演进 [ADR-0016](./0016-production-action-facts.md)、[ADR-0017](./0017-uniform-two-fact-feedback.md) 与 [ADR-0018](./0018-generation-policy-and-candidate-selection.md) 所承接的反馈内容边界,取代现行设计中“只回喂行动事实、不回喂优化试跑胜负或排名”的限制。旧 ADR 保留各自决策时的历史表述,不改写为当时已提供成绩反馈。三个有效阶段、两次反馈、阶段诊断修复与传输重试额度、执行预算和默认关闭的开关行为继续沿用;最终候选保存终局事实,不触发额外反馈或改写。各阶段共享固定优化条件;独立选拔仍按预定独立计划的完整对局平均名次积分及既有并列均分规则确定冻结身份,选拔与正式评测结果仍不回喂。

接受额外输入上下文、终局旁证存储与读取校验成本,换取可核对的比赛结果。摘要仅来自真实完成的对局,权重与单位造价取当局 ruleset,积分复用既有排名器;不确定墙钟超时、执行故障或缺失终局不能伪造零分或完整结果。旧观测缺少终局事实时继续可读并标为未知,不追填历史。终局采集和计分投影留在 CLI,gen 只接收 schema 的纯数据摘要;保持包边界与公开出口白名单,不放宽 result 符号门禁。
