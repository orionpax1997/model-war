# 无得分来源回喂仅作为显式有限实验

默认生成继续把无得分来源作为观测。为了诊断已通过编译、静态校验与预算试跑但实际无交付/占点的脚本,允许显式启用一次观测修正机会:反馈事实,不指定策略;机会仍受原协议轮数上限约束,再次命中或无剩余轮数时照常冻结脚本。它不改变游戏淘汰条件或正式参赛验收,也不回喂正式赛季结果。

选择显式一次机会,而非把零读数当校验失败反复重试,是因为零读数不能证明脚本未尝试得分或违反契约,现有三个固定种子的读数也不足以制定永久淘汰阈值。前后候选观测分别保存,让报告能审计生成条件并区分最终候选表现;归档 meta 十一键保持原契约。
