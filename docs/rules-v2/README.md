# rules-v2:当前模型契约

这一份是**参赛模型唯一能读到的规则输入**,相当于本项目的公开 API 文档。它由代码、`packages/schema` 与 `rulesets/v2.json` 生成并受漂移门禁保护,**散文部分人工写、数字部分生成**。

| 文件 | 内容 |
|---|---|
| [rules.md](./rules.md) | 机制、结算顺序、确定性约束(数字表是生成物) |
| [api.md](./api.md) | 脚本可见的 API 面与常量(API 表是生成物) |

## 它为什么不能删

「代码是真源」不等于「规则文档可以删」:代码决定真实行为,但**模型写脚本时不能读代码**。这一份是代码与规则集事实的**投影**,不是另一套事实——所以它必须由生成流程产出,并由 `pnpm run check:drift` 保证不与真源分叉。

## 边界

- 数字的唯一真源是 [`rulesets/v2.json`](../../rulesets/v2.json);两份文档里的数值表由它生成,**散文里不抄取值**。
- 散文的修订**不升版本号**(见 [ADR-0008](../adr/0008-contract-prose-revision-does-not-bump-version.md));版本号只锚定规则集取值。
- 契约版本号三处一致:`rulesets/v2.json` 的文件名、本目录名、`packages/schema` 的版本常量;装载期不一致即拒跑。
- 规则版本不同的结果不进同一份排名。

历史版本见 [../rules-v1/](../rules-v1/)(只读快照,不再维护)。
